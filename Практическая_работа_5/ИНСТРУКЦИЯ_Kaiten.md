# ПР5 — инструкция: как быстро собрать доску в Kaiten и сделать скриншоты

Время: ~40 минут. Все тексты ниже — готовые, их нужно просто копировать в Kaiten.
Отчёт: [`ПР5_Отчет_Kaiten.docx`](ПР5_Отчет_Kaiten.docx) — в нём жёлтые рамки **«[ ВСТАВЬТЕ СКРИНШОТ ]»**, их нужно заменить скриншотами (номер скриншота указан в рамке).

> Интерфейс Kaiten периодически меняется. Если кнопка называется чуть иначе — ищите по смыслу (обычно через «+», «⋯» или правый клик).

## Шаг 1. Регистрация

1. Откройте https://kaiten.ru → «Попробовать бесплатно» / «Регистрация».
2. Введите e-mail и пароль, подтвердите почту.
3. В профиле укажите имя и фамилию (они будут видны как «ответственный» на карточках).

## Шаг 2. Пространство → 📸 Скриншот 01

1. В левой панели нажмите **«+»** рядом с «Пространства» (или «Создать пространство»).
2. Название: **`Гостиница Космос`**.
3. 📸 **Скриншот 01** — левая панель с пространством «Гостиница Космос».

## Шаг 3. Доска и колонки → 📸 Скриншот 02

1. Внутри пространства: **«Добавить» → «Доска»**, тип — простая доска (колонки «Очередь / В работе / Готово»).
2. Название доски: **`Разработка ИС «Космос»`**.
3. У колонки «Очередь» нажмите **«⋯» → «Редактировать/Переименовать»** → **`Запланированные`**.
4. (по желанию) в настройках колонки «В работе» задайте лимит WIP = 3.
5. 📸 **Скриншот 02** — доска с колонками, можно с открытым меню колонки.

## Шаг 4. Метки

Метки создаются прямо из карточки (поле «Метки»/«Теги» → ввести название → выбрать цвет). Используйте такие:

| Метка | Цвет |
|---|---|
| Анализ | жёлтый |
| Документация | серый |
| Требования | оранжевый |
| Проектирование | синий |
| БД | голубой |
| Дизайн | розовый |
| Backend | фиолетовый |
| Frontend | зелёный |
| Интеграция | бирюзовый |
| Тестирование | красный |
| Внедрение | коричневый |
| Важное – срочное | красный |
| Важное – не срочное | жёлтый |

## Шаг 5. Карточки (10 штук)

Как добавить: в колонке нажмите **«+ Добавить карточку»**, введите название, Enter. Затем кликните по карточке, чтобы открыть её, и заполните поля.
**Период (даты начала и окончания):** в карточке нажмите «+» → справа в колонке **«Поля» → «Timeline»** → задайте **дату начала 9:00 и дату окончания 18:00**. Поля «Срок» и «Даты» задают только одну дату — для графика они не подходят, их можно не заполнять. Без поля Timeline карточка не появится на диаграмме Timeline. **Ответственный:** назначьте себя.

**Обязательно по заданию:** ≥5 карточек, на ≥3 карточках — разные атрибуты (суммарно ≥9). Карточки 1–3 заполнены «по максимуму» — их и фотографируем.
