# ПР6 — инструкция: ветки, pull request, форк и скриншоты на GitHub

Время: ~30 минут. Всё делается в браузере, ничего устанавливать не нужно.
Отчёт: [`ПР6_Отчет_GitHub.docx`](ПР6_Отчет_GitHub.docx) — жёлтые рамки **«[ ВСТАВЬТЕ СКРИНШОТ ]»** заменить скриншотами (номер указан в рамке).

Репозиторий: **https://github.com/mfostorm/panevina** (название = фамилия, как требует задание).

> Файлы для загрузки в ветки лежат в папке [`файлы_для_веток`](файлы_для_веток): скачайте их на компьютер
> (открыть файл → кнопка «Download raw file» ⤓).

---

## Шаг 0. Сделать основную ветку `main` (один раз)

Сейчас все файлы лежат в ветке `claude/lab-reports-bn2ae5`. Её нужно переименовать в `main`:

1. Откройте репозиторий → нажмите на выпадающий список веток (слева над файлами) → **View all branches**.
2. Напротив `claude/lab-reports-bn2ae5` нажмите ✏️ (**Rename branch**) → введите `main` → **Rename branch**.
3. Проверьте: на главной странице репозитория выбрана ветка `main`, видны папки ПР и README.

> Если у вас уже есть ветка `main` с другими файлами — вместо переименования откройте pull request
> `claude/lab-reports-bn2ae5` → `main` и нажмите Merge.

Также положите свои отчёты **ПР1–ПР3** в папки `Практическая_работа_1…3` (в папке: **Add file → Upload files**).

## Шаг 1. Профиль и активность → 📸 02, 03

- 📸 **02** — ваш профиль `https://github.com/<логин>` (аватар, имя, репозитории).
- 📸 **03** — блок **contributions in the last year** (зелёные квадраты). Лучше делать в самом конце, после шагов 2–5, чтобы квадраты «позеленели».

## Шаг 2. Ветка `docs` → 📸 05

1. На главной странице репозитория откройте список веток → в поле введите `docs` → **Create branch docs from main**.
2. Убедитесь, что выбрана ветка **docs** → **Add file → Upload files**.
3. Перетащите 2 файла: `ПР4_2_ТЗ_ИС_Космос.pdf` и `context.jpg`.
4. В поле **Commit changes** напишите: `Добавлены ТЗ (PDF) и контекстная диаграмма (JPG)` → **Commit changes**.
5. 📸 **05** — ветка docs с этими файлами.

## Шаг 3. Ветка `prototype` → 📸 06

1. Переключитесь на **main** → в списке веток введите `prototype` → **Create branch prototype from main**.
2. В ветке **prototype**: **Add file → Create new file**. Имя файла: `Назначение СКВ.txt`. Текст:

```text
GitHub – крупнейший веб-сервис для хостинга IT-проектов и их совместной разработки.
Веб-сервис основан на системе контроля версий Git. Ознакомиться с документацией
по работе с GitHub можно на сайте GitHub Help.
Репозиторий panevina хранит материалы проекта ИС «Космос» (ООО «Гостиница Космос»).
```

3. **Commit changes…** → сообщение `Создан файл Назначение СКВ.txt` → **Commit changes**.
4. Там же **Add file → Upload files** → загрузите `hotel_price_calc.py` → сообщение `Добавлен прототип модуля расчётов hotel_price_calc.py` → **Commit changes**.
5. 📸 **06** — ветка prototype с `.txt` и `.py`.

## Шаг 4. Список веток → 📸 04, 07

- 📸 **04** — главная страница репозитория, ветка **main** (папки ПР + README).
- 📸 **07** — список веток: откройте `https://github.com/mfostorm/panevina/branches` — должны быть **main, docs, prototype**.

## Шаг 5. Слияние prototype → main (pull request) → 📸 08

1. Появится жёлтая плашка **prototype had recent pushes → Compare & pull request** (или вкладка **Pull requests → New pull request**, base: `main`, compare: `prototype`).
2. Заголовок: `Прототип модуля расчётов ИС «Космос»` → **Create pull request**.
3. **Merge pull request → Confirm merge**.
4. 📸 **08** — страница pull request со статусом **Merged**.

> Ветку `docs` в main **не сливаем** — она остаётся отдельной ветвью документации (в отчёте так и описано).

## Шаг 6. Форк → 📸 09

1. Откройте https://github.com/django/django → кнопка **Fork** (справа вверху) → **Create fork** (галочку «Copy the main branch only» можно оставить).
2. 📸 **09** — ваш репозиторий `django` с надписью **forked from django/django**.

## Шаг 7. Kaiten → 📸 01

В Kaiten переместите карточку 3 «Общее описание ИС и разработка ТЗ» в **Готово**, карточку 4 «Проектирование архитектуры и базы данных» — в **В работе**. 📸 **01** — вся доска.

## Шаг 8. Вставка скриншотов в отчёт

Кликните в жёлтую рамку → удалите текст → вставьте скриншот (Ctrl+V) → удалите рамку таблицы (правый клик → «Удалить таблицу»), подпись «Рисунок N – …» оставьте.

| № скриншота | Рисунок в отчёте | Что на нём |
|---|---|---|
| 01 | Рисунок 2 | доска Kaiten (прогресс) |
| 02 | Рисунок 3 | профиль GitHub |
| 03 | Рисунок 4 | календарь активности |
| 04 | Рисунок 5 | ветка main |
| 05 | Рисунок 6 | ветка docs |
| 06 | Рисунок 7 | ветка prototype |
| 07 | Рисунок 8 | список из 3 веток |
| 08 | Рисунок 9 | pull request Merged |
| 09 | Рисунок 10 | форк django |

Готовый отчёт с вставленными скриншотами загрузите обратно в папку `Практическая_работа_6` (Add file → Upload files, ветка main).
